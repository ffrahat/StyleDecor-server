# 🎨 StyleDecor Server

A modern backend for appointment & service management system tailored for local decoration businesses.  
Handles bookings, payments, decorators management, and analytics with Firebase authentication and Stripe payments.

---

## 🚀 Live Backend

Currently deployed backend (if any) can be added here:  
`API Base URL: https://style-decor-server.vercel.app`

---

## 🎯 Project Overview

The StyleDecor server powers:

* Secure user authentication & authorization (Firebase Admin)
* Service booking management
* Decorator assignment & availability management
* Payment processing using Stripe
* Analytics & reporting
* REST API endpoints consumed by frontend React app

---

## ⭐ Key Features

### 🔹 User-Facing Endpoints

* Fetch available services & packages
* Get booking status & history
* Submit booking requests
* Process online payments (Stripe)
* Cancel or update bookings

### 🔹 Admin / Business Endpoints

* Manage users & decorators
* Approve/decline bookings
* Assign decorators to projects
* Track service progress
* Manage payments & refunds
* View analytics & reports

---

## 🧩 Technologies & NPM Packages

* **Node.js** & **Express** — backend framework
* **MongoDB** — database for users, bookings, and services
* **Firebase Admin SDK** — authentication & token verification
* **Stripe** — secure online payment processing
* **CORS & dotenv** — environment management & cross-origin support
